<h3>Problem Statement</h3>

<p>Managers currently receive CSV reports from Amazon Connect, making it difficult to:</p>
<p>- Monitor performance </p>
<p>- Identify trends </p>
<p>- Track service levels </p>
<p>- Make operational decisions</p>

<h4>Problem</h4>
Manual reporting is:

<p>Time consuming</p>
<p>Error prone</p>
<p>Difficult to analyse over time</p>

<h4>Solution</h4>
<p>Build a cloud-based analytics platform using AWS services that automatically stores, processes, and visualises contact centre performance data.
</p>

<h4>Business Objectives</h4>
<p>1. Centralize contact centre reporting </p>
<p>2. Reduce manual reporting effort</p>
<p>3. Improve operational visibility</p>
<p>4. Track key KPIs </p>
<p>5. Enable self-service analytics</p>

<h4>Success Criteria:</h4>
<p>- View daily call volumes</p>
<p>- Identify missed calls</p>
<p>- Monitor agent performance</p>
<p>- Measure average handle time</p>
<p>- Generate operational insights</p>
