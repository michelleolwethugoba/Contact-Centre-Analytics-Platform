# Contact-Centre-Analytics-Platform

<h3>Business Scenario</h3>

<p>A contact centre manager needs visibility into:</p>

<p>- Missed calls</p>
<p>- Abandoned calls</p>
<p>- Average Handle Time (AHT)</p>
<p>- Agent performance</p>
<p>- Customer satisfaction trends</p>

<p>Data is exported from Amazon Connect and stored in AWS for reporting.</p>
